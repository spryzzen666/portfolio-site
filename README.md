# Asankhan Dauletov — Portfolio

Personal portfolio / landing site built with **React + TypeScript + Vite**.

**[Live demo](https://portfolio-site-spryzzen.vercel.app)**

## Sections

- **Hero** — name, role, status badge, key stats
- **Services** — landing pages, business websites, web apps
- **Projects** — live hosted projects with stack chips and links
- **Skills** — animated skill bars
- **Contact** — email CTA + socials

## Tech

- React 18, TypeScript (strict), Vite
- Plain CSS (dark theme, responsive, CSS variables, animations)

## Run locally

```bash
npm install
npm run dev      # → http://localhost:5173
```

Prod build:

```bash
npm run build
npm run preview
```
