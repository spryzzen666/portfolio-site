# Asankhan Dauletov — Portfolio

Personal portfolio / landing site built with **React + TypeScript + Vite**.

**[Live demo](https://portfolio-site.vercel.app)**

## Sections

- **Hero** — name, role, short intro
- **Services** — landing pages, business websites, web apps
- **Projects** — live hosted projects (Task Manager, FX-TERMINAL 3025, Innoverse) with links
- **Skills** — animated skill bars
- **Contact** — email CTA + socials

## Tech

- React 18, TypeScript (strict), Vite
- Plain CSS (dark theme, responsive, CSS variables)

## Run locally

```bash
npm install
npm run dev      # → http://localhost:5173
```

Prod build:

```bash
npm run build
npm run preview
```
